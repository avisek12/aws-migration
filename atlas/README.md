# Migration Atlas

A single-page, navigable version of this playbook — the same content as `docs/`, condensed into one scrollable reference with a sticky section rail, architecture diagrams, expandable step-by-step cards for each of the 6R strategies, and an interactive execution checklist.

- **Live version (recommended):** https://claude.ai/code/artifact/5bbc80cf-53e3-41e1-84a6-02547984e138 — hosted on claude.ai, private to the owner. The execution checklist (§08) saves your progress automatically here (synced via the page's built-in storage) and can be shared from the page's share menu if you want a teammate to see it.
- **[index.html](index.html)** in this folder is the same file, checked in for reference/version history. Opening it directly in a browser works for reading, but the checklist will only persist progress to that browser's local storage (no cross-device sync) since the live-sync feature depends on the claude.ai hosting runtime.

To publish an update: edit `index.html` here, then republish it to the same claude.ai URL above so the live link keeps working (or ask Claude to do it) — just replacing this file will not update the hosted page.
